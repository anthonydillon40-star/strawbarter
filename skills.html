How It Works — Skill Swap Rules

🤝 Fair Swap — No Money, Ever

  • • This is a SKILLS-ONLY exchange. No cash, no payments, no fees — ever.
  • • All arrangements are direct between users. Message → agree → swap — entirely between yourselves.
  • • Time is the best currency. Aim for roughly equal time/effort on both sides — be fair 💚
  • • Platform NEVER handles payments or services. We are a listing board only — all work is agreed & delivered directly.

✅ Offering Your Skill

  • • Be clear about what you CAN & CAN'T do
  • • State experience level & location
  • • Be realistic about timeframes
  • • Update when your skill is no longer available

🤝 Requesting a Swap

  • • Be polite & prompt — reply quickly
  • • Offer something fair in return — match effort
  • • Agree scope, time & location BEFORE starting
  • • Say thank you — good vibes only ✨

⚠️ Safety & Best Practice

  • • Meet in public first if possible — daylight, safe location
  • • Agree all details clearly before any work starts
  • • Be honest about skills — don't overpromise
  • • If in doubt, trust your gut — no obligation to swap

By using this section: All skill swaps and arrangements are entirely between the two parties. This platform provides listing information only — we do not inspect, verify, or guarantee work, safety, or outcomes. Always meet safely, agree terms upfront, and respect each other's time and abilities. Build community, share skills, help each other grow! 💚 © 2026 Skill Swap — part of STRAW Barter.
