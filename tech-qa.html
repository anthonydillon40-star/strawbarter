🪟 Windows (1–300)

Q1: How do I make Windows faster?
A: Press Win+R → type msconfig → Startup → disable all unnecessary apps. Also: Settings → Privacy → Background apps → turn off. Delete temp files: Win+R → %temp% → Delete all. Restart.
Q2: How do I factory reset Windows?
A: Settings → Update & Security → Recovery → Reset this PC → Get started → Choose "Remove everything" for full reset. ⚠️ Back up files first!
Q3: My Windows is very slow on startup
A: Task Manager (Ctrl+Shift+Esc) → Startup tab → disable everything except antivirus. Check disk space — need at least 15% free. Run Disk Cleanup → right-click C: → Properties → Disk Cleanup.
Q4: How to find files fast in Windows?
A: Press Win key immediately and start typing. Or use Everything search engine (free, much faster). In File Explorer: Ctrl+F in top-right search box.
Q5: How do I stop pop-up ads on Windows?
A: Settings → System → Notifications → turn off "Get tips and suggestions". Install uBlock Origin in browser. Run full virus scan. Check installed programs — uninstall anything suspicious.
Q6: How to take a screenshot?
A: Win + Shift + S → draw area → saved to clipboard. Or Win + PrtScn → saves full screen to Pictures folder. Alt + PrtScn = active window only.
Q7: How do I free up disk space?
A: Settings → System → Storage → run Disk Cleanup. Empty Recycle Bin & Downloads folder. Uninstall unused apps. Move large files to USB/external drive. Delete old Windows updates.
Q8: How to change default apps?
A: Settings → Apps → Default apps. Click the current default and choose your preferred app (browser, photos, music, etc.).
Q9: My keyboard types wrong characters
A: You likely switched keyboard layout. Press Alt + Shift to toggle. Settings → Time & Language → Language → set English (UK) as default. Restart.
Q10: How to right-click without a mouse?
A: Select item → press Shift + F10. Or press the menu key on keyboard (between right Alt & Ctrl). On touchscreen: long-press the item.

📱 Mobile Phones (301–600)

Q301: My battery drains too fast — what can I do?
A: Lower screen brightness. Turn off Bluetooth/Wi-Fi when not using. Turn off Background App Refresh. Location Services → set to "While Using" or off. Turn off Always-On Display. Disable vibration. Check battery usage in Settings — see which app is draining most.
Q302: How do I free up storage space?
A: Delete old photos/videos or back up to Google Photos/iCloud. Offload unused apps. Clear cache: Settings → Storage → Clear Cache. Delete downloaded music/podcasts. Delete old messages & attachments.
Q303: Phone won't charge properly
A: Clean charging port with a wooden toothpick — lint is the #1 cause. Try different cable & wall plug. Restart phone. Check if port is loose. Never force the cable.
Q304: Touchscreen not responding correctly
A: Restart phone first. Clean screen — remove screen protector if damaged. Update software. If still unresponsive — it may be a hardware fault needing repair.
Q305: How do I transfer photos to computer?
A: Connect with USB cable → unlock phone → allow access → open DCIM folder. Or use Google Photos / iCloud / OneDrive — upload on phone, download on computer. Or email them to yourself.
Q306: Forgot my PIN / Passcode
A: You'll need to factory reset. ⚠️ This deletes all data — restore from backup. On iPhone: connect to computer → Finder/iTunes → Restore. On Android: use Find My Device → Erase, or Recovery Mode.
Q307: No signal / No service
A: Toggle Airplane mode ON then OFF. Restart phone. Check SIM card — remove & reinsert. Check network coverage in your area. Update carrier settings. Try different SIM to rule out phone issue.
Q308: Apps keep crashing
A: Update the app in App Store / Play Store. Restart phone. Clear app cache (Android) or offload app (iPhone). Uninstall & reinstall. Check phone storage — low space causes crashes.
Q309: Phone got wet — what now?
A: ⚠️ DO NOT TURN IT ON OR CHARGE IT. Dry gently with towel. Place in dry air — silica gel packets best, rice works but can leave dust. Wait 24–48 hours fully dry before trying to power on.
Q310: How to block nuisance calls?
A: Tap number → Block this Caller. Turn on Silence Unknown Callers. Register with TPS (UK free service). Use carrier call-blocking services. Report numbers to Ofcom.

📶 WiFi & Internet (601–900)

Q601: Slow internet — how to fix?
A: Restart router — unplug for 30 seconds, plug back. Move router higher & central. Reduce distance — walls block signal. Change WiFi channel (router admin page). Disconnect unused devices. Run speed test at speedtest.net.
Q602: Connected to WiFi but no internet
A: Restart router. Forget network → reconnect. Check router lights — no DSL/light means line issue. Contact provider. Try different device — isolate problem.
Q603: Forgot my WiFi password
A: Check label on bottom/back of router. On Windows: Settings → WiFi → Manage Known Networks → Properties → Show Characters. On iPhone: share password to another Apple device. Or log into router admin (192.168.0.1 or 192.168.1.1).
Q604: WiFi keeps dropping / disconnecting
A: Router overheating — give it space. Update router firmware. Change channel (neighbours interfere). Check cables — tighten them. Replace old router. Keep away from microwaves, cordless phones, baby monitors.
Q605: How to make WiFi signal stronger?
A: Central location, high up. Away from walls & metal. No obstacles between router & devices. Update router firmware. Consider WiFi extender / mesh system for large homes.
Q606: Can't see my WiFi network
A: Check router is on & working. Restart router. Ensure SSID broadcast is ON (router settings). Move device closer. On device: toggle WiFi off/on. If hidden — add manually with network name & password.
Q607: Ethernet works but WiFi doesn't
A: Router WiFi radio may be off — check button or admin page. Update WiFi driver on computer. Check device isn't in Airplane mode. Restart router.
Q608: How to change WiFi name & password?
A: Open browser → go to 192.168.0.1 or 192.168.1.1 → log in (admin/admin or on router label) → Wireless → change SSID & WPA2/WPA3 password → Save.
Q609: Internet light is red / no connection
A: Red light = no signal from provider. Check cable at wall & router. Restart multiple times. Check service status in your area. Contact ISP — line may be down.
Q610: 2.4GHz vs 5GHz — which to use?
A: 5GHz = faster but shorter range (best close by). 2.4GHz = slower but goes through walls better (best far away or thick walls). Most modern routers offer both.

📧 Email (901–1200)

Q901: Can't send emails but can receive
A: Check Outgoing SMTP server settings — usually port 587 (TLS) or 465 (SSL). Authentication required = YES. Password correct. Internet connection working. Recipient address not bouncing.
Q902: Emails not arriving / missing
A: Check Spam/Junk folder first. Check Filters / Rules — may be auto-sorting. Check storage limit — full inbox blocks new mail. Ask sender to check for bounce message. Search All Mail.
Q903: How do I recover my email password?
A: Click "Forgot Password" on login page. Verify via recovery phone or alternate email. Create new strong password. Update recovery info immediately after regaining access.
Q904: Emails going to Spam folder
A: Open email → click "Not Spam" / "Mark as Safe". Add sender to Contacts / Safe Senders list. Avoid all-caps & too many links in emails.
Q905: How to attach files & send?
A: Click paperclip 📎 icon → select file → Open → Send. Large files: use Google Drive / OneDrive / WeTransfer instead of direct attachment (most providers limit 20–25MB).
Q906: Too many spam emails — how to stop?
A: NEVER click "Unsubscribe" in spam — confirms your email is active. Mark as Spam. Delete & empty trash. Don't post email publicly online. Use separate email for forms/signups.
Q907: How to create a new email address?
A: Gmail: mail.google.com → Create account. Outlook: outlook.com → Create free account. ProtonMail: proton.me (privacy-focused). Choose strong password, add recovery phone & email.
Q908: Email says 'Account full' — won't send
A: Delete old large emails — especially those with attachments. Empty Trash & Spam folders. Archive instead of keeping everything. Buy more storage if needed.
Q909: How to set up email on phone?
A: Settings → Mail/Accounts → Add Account → choose provider → enter email & password → follow prompts. For custom email: use IMAP settings from your provider.
Q910: Phishing email — what should I do?
A: ⚠️ DO NOT click any links or download attachments. Forward to report@phishing.gov.uk (UK). Delete it immediately. Legitimate companies NEVER ask for passwords or bank details via email.

🖨️ Printers (1201–1500)

Q1201: Printer says 'offline' but it's on
A: Check cables or WiFi connection. Restart printer & computer. Settings → Devices → Printers → Open Queue → cancel all jobs → "Use Printer Online". Run Printer Troubleshooter.
Q1202: Printout streaky / faint / missing lines
A: Run Head Cleaning utility from printer software. Align print heads. Check ink/toner levels. Gently wipe cartridge nozzles with lint-free cloth & warm water. Replace dried-out cartridges.
Q1203: Paper jam — can't clear it
A: ⚠️ Turn off & unplug first. Gently pull paper straight out — NOT at an angle. Open all access doors. Check for small torn pieces. Fan paper before loading — don't overfill. Use correct paper size.
Q1204: Printer won't connect to WiFi
A: Use WPS button method — press WPS on router then printer within 2 mins. Or connect via USB first → set up WiFi from software. Ensure 2.4GHz network — many printers don't support 5GHz.
Q1205: Ink cartridge not recognised
A: Remove & reinsert firmly. Clean gold contacts on cartridge & inside printer with dry cloth. Turn printer off for 30 secs then on. Some printers block non-brand cartridges — look for firmware update option.
Q1206: Printer says 'out of ink' but it's new
A: It's a chip estimate — not actual level. Remove & reinstall. Ignore message — it will print until truly empty. Some printers require holding Resume/Reset button for 5–10 secs to override.
Q1207: Prints too slow — takes forever
A: Set print quality to Draft / Standard instead of Best. Reduce DPI/resolution. Use USB instead of WiFi. Update printer driver. Large images & high-res PDFs print slower — normal.
Q1208: How to scan a document?
A: Place face-down on glass → press Scan button on printer OR on computer: Settings → Devices → Printers & Scanners → Open Scanner → Preview → Scan → Save. On phone: use Google Drive or Notes app camera scan.
Q1209: Won't print in black only
A: Settings → Print → Properties → Color → Grayscale / Black & White only. Some printers refuse if ANY color cartridge is empty — replace or hold Reset button.
Q1210: Paper keeps jamming constantly
A: Use correct paper thickness. Don't mix paper types. Fan paper before loading. Don't overfill tray. Check paper guides are snug but not too tight. Remove dust inside printer.

🌐 Browsers (1501–1750)

Q1501: Browser very slow — how to speed up?
A: Clear cache & cookies (Ctrl+Shift+Delete). Remove unused extensions. Close extra tabs. Update browser. Disable hardware acceleration in Settings. Restart computer.
Q1502: How to block pop-up ads?
A: Settings → Privacy & Security → Pop-ups → Block. Install uBlock Origin (free — best ad blocker). Never click "Allow Notifications" on suspicious sites.
Q1503: Forgot website password — how to recover?
A: Click "Forgot Password" on login page. Check browser saved passwords: Chrome: Settings → Autofill → Passwords. Edge: same. Always use a password manager (Bitwarden — free & recommended).
Q1504: Website won't load — "This site can't be reached"
A: Check your internet first (try another site). Hard-refresh with Ctrl+F5. Clear cache. Try another browser or device — isolates the problem. The site itself may be down — try later. Check your device date/time is correct (it affects HTTPS).
Q1505: How to clear cache & cookies?
A: Press Ctrl+Shift+Delete in any browser → tick "Cached images and files" + "Cookies" → time range "All time" → Clear data. You'll be signed out of most sites — have passwords ready.
Q1506: How to change my default browser?
A: Windows: Settings → Apps → Default apps → Web browser → choose your preferred browser. On first launch the new browser may ask to confirm — say yes.
Q1507: Incognito / Private mode — what does it actually do?
A: It only stops the browser saving history, cookies & form data for that session. It does NOT hide you from your ISP, employer or school network, and downloads/bookmarks are still saved.

🔒 Security (1751–2000)

Q1751: I think I've been hacked — what do I do?
A: 1) Regain access via "Forgot password" → recovery phone/email. 2) Change the email password first, then others. 3) Sign out of all devices/sessions. 4) Check account activity/login history. 5) Scan device for malware. 6) Enable two-factor authentication. 7) Warn contacts — hackers often email from your account.
Q1752: How do I create a strong password?
A: Use 3+ random words, e.g. candle-fish-marble — easy to type, hard to crack. Add numbers/symbols if required. Never reuse passwords across sites. Use a password manager (Bitwarden — free) to generate & remember them.
Q1753: What is two-factor authentication (2FA) and why use it?
A: An extra code required at login, so a stolen password alone isn't enough. Use an authenticator app (Google Authenticator or Authy) where possible — SMS is less safe (SIM-swap risk) but far better than nothing. Save the 2FA backup codes when you set it up — print them.
Q1754: How do I check if my email has been in a data breach?
A: Visit haveibeenpwned.com — enter your email. It lists known breaches for that address. If listed: change that password everywhere you reused it, and enable 2FA.
Q1755: Is public WiFi safe to use?
A: Avoid online banking on public WiFi. Prefer mobile data for sensitive tasks. Verify the exact network name with staff — hackers run fake hotspots. Turn off auto-connect to open networks. Use a VPN if you must work on public WiFi.
Q1756: What is phishing, exactly?
A: Fake emails/texts/calls pretending to be your bank, HMRC, Amazon, Netflix, etc. Goal: steal passwords or card details. Tip-offs: urgency, threats, misspellings, generic greetings, odd sender addresses, unexpected attachments. Delete — don't click.
